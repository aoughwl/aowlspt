## The 2.5-hour blocker, and how it was found

Every host and backend build failed with a compiler-internal crash
(`getOrQuit: missing key`, no file named). Falsified in isolated worktrees:
corrupt cache, the driver's new pre-step, uihooks.nim (an include-bisect
ordering artifact). ROOT CAUSE: the jsonpath move left `host/common/
jsonpath.nim` as `import aowlspt/jsonpath; export jsonpath`; a whole-module
re-export kills nimony's hexer. Fix: a plain `include` (commit cb9a816).
Shared tree green at 22:2x (721s). Rule: never `export <module>` here.
