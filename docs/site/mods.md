# The mods

Everything below ships with aowlspt and is switched on or off in the
[mod manager](mod-system.md). Each one declares its own settings, so each one has
a section in the [F12 panel](settings.md).

---

## Singleplayer

`aowl.tarkov` — **the emulator itself.** This is the mod that makes the game
work offline: it is a Tarkov server, and it is written as an ordinary mod, using
nothing a mod cannot use.

| | |
|---|---|
| **Login and profiles** | create, select, nickname validation, voice, appearance, persistence across restarts |
| **Static tables** | items, globals, handbook, customisation, locales, languages, quests, achievements, prestige |
| **Inventory** | move, split, merge, transfer, remove, fold, toggle, tag, swap, examine |
| **Traders** | assorts, per-trader prices, buy and sell, and the loyalty level your turnover earns |
| **Flea market** | offers built from the handbook and the assorts, search and filter, your own offers — add, buy, remove and renew |
| **Quests** | accept, hand over, complete, fail, with the conditions actually evaluated and the rewards paid |
| **Repeatable quests** | dailies, the weekly and the scav's, generated from the database's own skeletons and reward budget, with the reroll priced by the table |
| **Hideout** | area upgrades against the stage's real requirements, production and continuous production, the scav case, the gym |
| **Raids** | configuration, weather, match start and end, and generated loot — static containers, loose loot, ammo boxes, weapon presets |
| **Bots** | generated by role and difficulty, dressed from the loadout, mod and ammo tables, carrying what those tables put in their rig, pockets and pack |
| **Scavs** | a second character sharing the PMC's stash, with its own cooldown and its own Fence standing |
| **Skills** | Common and weapon Mastering, taken from the raid as a delta and run through the game's own curve |
| **Insurance** | premiums off the handbook, cover bought before the raid, returns that survive a restart — with the covering letter in the trader's own words |
| **Repair** | at a trader for the template's price, or with a kit for the kit's charge, and a permanent bite out of the maximum either way |
| **Health** | healing and eating between raids, and treatment at a trader priced from the game's own health config |
| **Mail** | dialogs, messages, attachments and redeeming them; read, pin, unpin, remove |
| **Personal** | notes, map markers, builds, the wishlist, favourites, pins, the hotkey bar |

### What you can change

The Singleplayer section of the [settings panel](settings.md) is the game's own
dials:

- **Edition** — Standard through Unheard, which decides your stash and your
  starting kit — and **side**, and how many roubles you begin with
- **Flea market** — price spread, how long an offer lives, how many offers the
  market holds, and how long a sale takes to clear
- **Loot** — multipliers per loot class, and a ceiling on how much a raid
  generates
- **Bots** — the default population limit
- **Scav** — cooldown between runs, and how fast Fence's standing moves
- **Insurance, mail, traders, quests, hideout, skills** — each with its own
  block
- **Spawn items** — search the entire item database, pick a count and a
  condition, and put it in your stash
- **Server value modifiers** — a generated set of rows over the server's own
  tunable values, unset by default, for anything the sections above do not name

### The request does not get to do the arithmetic

Nothing in a request is believed on its face, and this is what makes the economy
hold together over a long profile.

- **Selling** is priced by the handbook and counted against the item's real
  stack, so one water bottle cannot be sold as five.
- **Buying** is priced by the offer's own barter scheme and bounded by the
  assort's stock, so a body naming one rouble does not buy the rifle.
- **A quest handover** credits the condition by what your profile actually
  holds, not by the count in the body.
- **A repair** is priced and sized by the item, so asking to restore 9,999
  points of a 40-point hole pays for 40.
- **A hideout upgrade** resolves every requirement — items, area levels, trader
  loyalty, skill levels — verifies all of them, and only then takes anything.

Money is **stacks, not a balance**. Paying 25,000 from a stack of 500,000 edits
that stack; paying from three stacks of 10,000 consumes two and edits the third.
A payout goes into stacks that already exist, up to the template's maximum,
before it opens a new one — so a long profile does not end up with a stash full
of loose change.

## Bot AI

`aowl.sain` — how the AI behaves, and how much of it there is.

Bots make layered decisions — fight, seek cover, search, regroup, retreat —
rather than running one script, and they have **personalities** that weight
those layers differently. Squads coordinate.

**Difficulty is a band, not a slider:**

| band | |
|---|---|
| `easy` | forgiving — for learning a map |
| `lessdifficult` | below stock |
| `default` | the intended experience |
| `harderpmcs` | scavs as they were, PMCs that punish mistakes |
| `veryhard` | every role sharpened |
| `deathwish` | as hard as the tuning goes |

You can also force one personality on everything, which is the fastest way to
see what a personality actually does.

**Per-role tuning**, separately for **PMC**, **Scav**, **Boss** and **Zombie**:
engagement distance, how long they wait before searching for an enemy, whether
they will search at all, the health at which they break off, and whether they
shift cover position under fire.

**Population is part of the same mod.** How many bots a raid gets, per role, and
how the raid refills as they die — turn a map into a quiet stalk or a shooting
gallery without touching anything else. Bot roles and factions are defined
through an API other mods build on, so a mod that adds a faction adds it to the
same tables Bot AI is tuning.

## FOV

`aowl.fovfix` — field of view that stays where you put it, including while
aiming and while scoped, which is where the game otherwise puts it back.

Optic and non-optic FOV are separate multipliers, so you can widen your hipfire
view without changing what a scope looks like. Sensitivity multipliers come with
them — 1x, 4x and high magnification each get their own — because a wider FOV
that does not adjust sensitivity just makes aiming feel wrong in a new way.

**Zoom** is bound to **M** by default, hold-to-zoom, and both the key and the
hold-versus-toggle behaviour are settings.

## Graphics

`aowl.graphics` — colour grading and post-processing that the base game does not
expose.

**Tonemapping.** Choose **AgX** or **ACES**. AgX holds highlights and skin tones
under bright light where the stock curve clips them; ACES is the punchier,
higher-contrast filmic look.

**Presets**, each a complete starting point you can then adjust:

| preset | what it looks like |
|---|---|
| **neutral** | the game, corrected — the tonemap and nothing else |
| **filmic** | more contrast, rolled-off highlights, a cinema curve |
| **cold-clinical** | blue-shifted, desaturated, hard — winter and concrete |
| **warm-cinematic** | amber lift, richer midtones, softer shadows |
| **night-owl** | lifted shadows and reduced glare for night raids |

**The individual controls**, under whichever preset you started from:

- **Clarity** — local contrast, which pulls detail out of flat surfaces
- **Vibrance** — saturation that spares what is already saturated
- **Sharpening** — edge definition, tuneable rather than on/off
- **Bloom** — how far bright sources bleed
- **Vignette** — corner falloff
- **Dither** — breaks up banding in dark gradients, which is what makes a night
  sky look like a photograph instead of a topographic map
- **Grade, white balance, and lift/gamma/gain** — full three-way colour
  correction for anyone who wants to build a look from scratch
- **Film and lens** — grain and the optical touches that go with it

Choosing a preset **owns** every look slider under it; set the preset to
`custom` to take the wheel, and your adjustments stay yours.

### What Graphics does not do

Nothing here replaces the maps' own art. Tarkov's built-in locations are
compiled into the client, not shipped as loadable bundles, so a texture pack
cannot repaint Factory. Graphics changes how the image is *graded*, not what is
in it.

## Maps

`aowl.maps` — a **radar** and **direction indicators**, drawn over the game from
one guarded position feed.

The radar is a top-down minimap at a radius you choose, showing bots and other
players, at a refresh rate you choose. Size and screen position are yours;
so is whether it rotates to your facing or stays north-up. Indicators put the
same information at the edge of the screen instead, for when a radar is more
than you want.

Everything it draws comes off a single position feed with a frame budget, so a
busy raid costs you the budget and not your frame rate.

## Textures

`aowl.textures` — texture replacement from a pack you point it at, for content
that ships as loadable asset bundles.

You choose a pack root, a quality tier, a VRAM budget it will not exceed, and
which material categories it is allowed to touch — metal, wood, concrete, brick,
fabric, ground — so a pack can be used for exactly the surfaces you wanted it
for. A confidence floor governs how sure a match must be before it is made, and
every match can be logged so you can see what it actually did.

Textures ships out of the default lists on purpose: it needs a pack, and there
is no pack in the box.

**Tarkov's built-in maps are not bundles.** Factory and its siblings are
compiled into the client, so a texture pack does not repaint them.

## Admin Menu

`aowl.admin` — press **F6**. The tools for testing things, and for playing
however you like.

- **ESP** — see players and bots through geometry, out to a distance you set
- **Godmode** — no damage taken
- **Infinite stamina**
- **Item spawner** — search the whole item database by name, pick a count and a
  condition, and it lands in your stash. The search is live: it queries the
  server as you type, which is how "pick one of several thousand item ids"
  becomes a setting rather than a bespoke screen

The Admin section of the settings panel is mostly a pointer at F6 — the live
surface is the in-game menu, not the settings page.

## Debug

`aowl.debug` — press **F3**. A Minecraft-style info overlay drawn as real Unity
UI, in the game's own font and canvas, scaling with the game's own resolution.

The panel is made of **widgets you choose and arrange**. Each is draggable, each
can be turned off, and the set you build persists.

| widget | shows |
|---|---|
| `fps` | frames per second, plus the host's own tick counter |
| `frame` | how many times the per-frame hook has fired |
| `build` | host name and version, and the client build |
| `map` | the current location, or `menu` |
| `raid` | whether a raid is live |
| `bots` | registered / AI / alive counts |
| `pos` | your world position |
| `rot` | your yaw and pitch |
| `botlist` | the nearest AI bots with world coordinates, and a dead marker |
| `note1` `note2` `note3` | free text of your own |

An unrecognised widget name prints as `?name` rather than vanishing, so a typo
is visible on screen instead of being a mysteriously missing row.

There is also a **per-mod profiler**: how long each loaded mod spends in its own
per-frame work, so a mod that costs you frames is identifiable by name rather
than by bisection.

The toggle key is a setting like any other — F3 is the default because it is the
Minecraft key.

## Waypoints

`aowl.waypoints` — the navigation data bots patrol on. Ten maps, 87 zones, 197
patrol routes and 8,556 points, ported from DrakiaXYZ's SPT-Waypoints.

There is nothing to configure and nothing to see. What it changes is where bots
go: without it they cluster around the spawns the base data gives them, and with
it they walk the map. If a raid feels empty in the middle and crowded at the
edges, this is the mod that fixes it.

## Interface

`aowl.uihub` — the **browser** half of the settings surface. Every setting the
F12 panel draws is also served as a web page at

```
https://127.0.0.1/aowlspt/ui/page/settings
```

with the same sidebar of mods, the same category and subcategory sections, the
same search, the same typeahead for large option lists — and deep links, so a
particular screen is a URL you can bookmark. It works whether or not the game is
running, which makes it the easy way to set a profile up on a second monitor or
from a phone on the same machine.

The certificate is self-signed, because it is your own machine talking to
itself.

Its own settings hold the launch hint — the "press F12" toast at startup — and
whether to show it at all.

## Mod Manager

`aowl.manager` — the registry, your lists, and what is currently live. See
[The mod system](mod-system.md).

Its row is protected: a selection can never switch off the thing that would
switch it back on.
